## 2. ТЗ

### R9. Карточка «Данные» растягивается на всю ширину и высоту левой панели

**Текущее состояние**: `inner` — окно внутри `left_canvas`; в `_left_scroll_state` (graphlab_app.py:458-471) при `<Configure>` canvas выполняется только `itemconfigure(win_id, width=...)`. Карточка создаётся в :474 как `self._card(inner, "Данные", row=0)` (stretch=False → sticky="ew").

**Требования**:
1. R9.1. Добавить `inner.columnconfigure(0, weight=1)` — карточка занимает всю ширину панели (за вычетом скроллбара).
2. R9.2. Создавать карточку «Данные» с `stretch=True` (sticky="nsew", строка 0 в `inner` получает weight=1) — при наличии свободного вертикального места карточка растягивается до нижнего края панели.
3. R9.3. В `_left_scroll_state`: если контент помещается в canvas (`content_h <= view_h`) — дополнительно `left_canvas.itemconfigure(win_id, height=view_h)`; при переполнении — естественная высота (`height=0`). Автоскрытие скроллбара (R6.2) не меняется.

**Критерии приёмки**:
- При 1–3 линиях: ширина карточки = ширина панели (свободного места справа нет), нижний край карточки упирается в низ панели, вертикальный скроллбар скрыт.
- При переполнении (много линий): карточка на всю ширину, естественная высота, вертикальный скроллбар появляется, прокрутка вверх/вниз работает (R6.2/R7.4 не нарушены).
- При ресайзе окна ширина карточки обновляется сразу (через `<Configure>` canvas), полей не обрезает.

## 4. Решения по открытым вопросам

1. **minsize** — остаётся 1024×576 (16:9, R8.2); повышать не требуется.
2. **Cap масштабирования 1.0** — мелкие изображения не растягиваются (качество), изображение центрируется во вкладке.
3. **Геометрия существующих пользователей** — `_restore_state` (graphlab_app.py:1196-1232) восстанавливает сохранённую геометрию из `%APPDATA%\GraphLab\config.json`, т.е. у текущих пользователей окно откроется в их последнем размере, а 1600×900 применится как дефолт при отсутствии config (чистая установка). Принудительно накрывать сохранённую геометрию не требуется — отдельное решение, если нужно.
4. **Версия .gslab** — остаётся 1: удаление ключа обратно совместимо (старые файлы читаются терпимо), README/ARCHITECTURE обновляются по S1; формального повышения version не требуется (CONVENTIONS §3.7).
